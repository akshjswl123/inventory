Item Report

Import POS CSV export (itemReportCsv.js). Leading metadata (Date:, Name:, …) and summary rows (Total) are skipped. Required columns: Date, Invoice No., Area, Item Name, Qty. Other columns are stored when mapped; extras are ignored. Upsert when the same invoice + date + item + area appears again (invoice + date required on every line).
